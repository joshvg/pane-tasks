# Pane Tasks

Pane Tasks (often just Pane) is a Liquid Glass-style to-do app for iPhone, iPad, and Apple Watch. A Mac version also exists. It is made by [Josh von Gersdorff](https://joshvg.me).

Apple App Review approved Pane Tasks on October 28, 2026. The App Store release is coming soon.

## Overview

Pane keeps tasks in buckets you can reorder. Each task can have notes and checklist items, and a per-task toggle controls whether those appear on the task card. Labels are yours to create and delete. A clean new-task screen is where new tasks start. iCloud syncs tasks across your devices, including deletions.

## Features by device

### iPhone, iPad, and Mac

- Tasks organized in reorderable buckets
- Custom labels you can create and delete
- Per-task notes and checklist items, with a per-task toggle to show them on the task card
- A clean new-task screen
- iCloud sync across devices, including deletions

The iPad layout includes the same features as iPhone and Mac.

### Apple Watch

The Apple Watch companion includes:

- Glass cards
- Checking off tasks
- Haptic reminders
- Complications

## Privacy and support

This repository is published with GitHub Pages at [joshvg.github.io/pane-tasks](https://joshvg.github.io/pane-tasks/).

- **Support:** [Support page](https://joshvg.github.io/pane-tasks/) ([index.html](index.html))
- **Privacy Policy:** [Privacy Policy](https://joshvg.github.io/pane-tasks/privacy.html) ([privacy.html](privacy.html))

The privacy policy describes how Pane handles your information. Tasks, buckets, labels, checklists, notes, and settings stay on your device. When you are signed in to iCloud, Pane syncs them through Apple's CloudKit in your own private iCloud database.
